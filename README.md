# LDE en español — archivo de traducciones

Sitio estático sin dependencias: HTML + CSS + un poco de JavaScript. No hay nada que compilar ni actualizar.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en github.com (p. ej. `lde-es`).
2. Sube todo el contenido de esta carpeta (botón *Add file → Upload files*).
3. *Settings → Pages → Source: Deploy from a branch → main / (root)* → Save.
4. En un minuto estará en `https://TU-USUARIO.github.io/lde-es/`.

## Añadir un número nuevo (5 minutos)
1. Sube el PDF a `pdf/` con el nombre `lde-AAAA-MM-es.pdf`.
2. Sube la portada a `img/` como `portada-AAAA-MM.jpg`.
3. Abre `data/numeros.js`, copia un bloque `{ ... }` al principio de la lista y cambia los datos.
